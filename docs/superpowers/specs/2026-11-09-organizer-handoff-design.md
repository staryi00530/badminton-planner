# Organizer device handoff and local copies

Approved behavior: user prepares on computer and runs on iPad; complete organizer setup includes private1–5 levels and preferred pairings. Add Use on this device for a loaded shared session; preserve the visible roster/config/plan/scores/live/completed/ledger and disconnect subscriptions/autosave. Transfer organizer setup creates a separate immutable handoff; recipient previews and explicitly accepts a local import. Ordinary public shares remain level-free.

Approaches: extending public shares with plaintext private levels would change their privacy contract; self-contained long URL snapshots are fragile for full rosters/history. Use an encrypted immutable snapshot stored with the existing Firebase shares transport and a short URL carrying its decryption key in the fragment. Web Crypto AES-256-GCM with fresh32-bytekey and12-byteIV; no new service or paid plan. Anyone with the complete transfer link can read the organizer setup; label it private. Ciphertext envelope contains no raw levels, names or aliases. Import fetches once, never subscribes or autosaves to source.

Transfer contains current roster/private identity metadata, player bank, attendance/quarantine, session/court settings, mixed/preferred pair settings, quality weights, generated plan, live/completed state, scores and immutable played ledger. Excludes authentication/PINs/tokens, undo/prompts, source saved-plan archive, and global all-time win/loss database. Active source metadata wins for matching permanent IDs; unrelated target player-bank entries remain. Session history is replaced, not merged with an unrelated target session. Global win/loss is not imported or re-credited.

Before replacing local active session, preserve a durable private device backup and offer download. Storage failure blocks replacement. Transfer import can configure a roster before generating a plan. Incorrect/missing keys, expired/malformed snapshots and network errors leave current session intact. Transfer expiry7days. Import clears transfer/share URL identifiers, sessionStorage share flags and stale active recovery actions; refresh restores the new local session.

Detach is disabled while a cloud write or unresolved Finish action is in flight. Disconnect synchronously invalidates old callbacks and pending autosave timers; no late fetch/subscription/loadLatest response may overwrite the copied local state. Keep retained historical draft backups but remove active retry journals for the disconnected share. Disconnected session needs no new plan identity: it is a local branch; later Share creates a new share ID.

Scope: beta only; no remote logging or court/parser redesign here. Verify source privacy, exact state/levels/preferences, separate-device import/refresh/reroll/Finish, no remote write after detach, pending and late remote races, invalid transfer non-destructive behavior, setup-only handoff, history preserved and target private bank retained.
